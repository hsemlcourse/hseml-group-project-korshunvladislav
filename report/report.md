## 1. Введение и постановка задачи

- **Цель проекта:** Спрогнозировать пожизненную ценность клиента (Customer Lifetime Value, CLV) интернет-магазина на основе демографических и поведенческих признаков. Это позволяет бизнесу сегментировать клиентов, оптимизировать маркетинговые бюджеты и повышать удержание ценных клиентов.
- **Формулировка задачи:** Регрессия (предсказание непрерывной числовой величины — `Lifetime_Value`).
- **Обоснование метрики качества:** Основная метрика — RMSE (Root Mean Squared Error).
Причины:
  - CLV — денежная величина, ошибка на крупных клиентах (с высоким CLV) критичнее для бизнеса. RMSE квадратично штрафует большие отклонения.
  - Дополнительно используются MAE (лёгкая интерпретация в абсолютных единицах) и R² (доля объяснённой дисперсии).
  - При сравнении моделей приоритет отдаётся RMSE.

## 2. Поиск и описание данных

- **Источник данных:** Датасет [Ecommerce Customer Behavior Dataset](https://www.kaggle.com/datasets/dhairyajeetsingh/ecommerce-customer-behavior-dataset) с Kaggle. Выбран, потому что содержит демографические, поведенческие признаки и целевую переменную `Lifetime_Value`, что идеально подходит для задачи CLV.
- **Описание датасета:**
  - **Объём:** 50000 строк, 25 столбцов
  - **Типы признаков:** числовые (возраст, частота логинов, длительность сессий, количество покупок и т.д.), строковые (страна, город, пол), бинарный флаг `Churned`
  - **Особенность:** данные статические (агрегированы по клиентам), нет временной привязки, что исключает временной data leakage. Объём данных достаточен для обучения сложных моделей (Random Forest, градиентный бустинг).

## 3. Обработка и подготовка данных

- **Полная очистка:**
  - Пропуски: обнаружены в колонках `Age`, `Session_Duration_Avg`, `Pages_Per_Session`, `Wishlist_Items` и др. Заполнены: числовые — медианой, категориальные — модой.
  - Дубликаты: отсутствуют.
  - Выбросы: выявлены с помощью boxplot для непрерывных признаков (nunique ≥ 10). Ограничены 99-м перцентилем.
  - Типы данных: категориальные признаки (`Gender`, `Country`, `City`, `Signup_Quarter`, `Churned`) приведены к типу category.
- **Работа с фичами:**
  - Исходное количество признаков: 24
  - Создано 5 новых признаков:
    - Login_Session_Product (взаимодействие частоты логинов и длительности сессии)
    - Recency_Score (обратная величина дней с последней покупки)
    - Engagement_Index (отзывы + активность в соцсетях)
    - Returns_Per_Purchase (доля возвратов на одну покупку)
    - Age_Group (возрастные категории)
  - Все категориальные переменные закодированы one-hot. Итоговое число признаков: 78.
- **Визуализации:**
  - Распределение CLV: длинный правый хвост (мало клиентов с очень высоким CLV).
  - Корреляционная матрица: наибольшая положительная корреляция у Total_Purchases и Average_Order_Value.
  - Scatter plot Total_Purchases vs Average_Order_Value с цветом по CLV показывает прямую зависимость.
  - Boxplot выбросов до/после обработки демонстрирует уменьшение экстремальных значений.
- **Сплит данных:**
  - Разбиение: train 70%, validation 15%, test 15% (случайное, с фиксированным seed=42).
  - Предотвращение data leakage: данные статические, все признаки исторические или демографические, не содержат информации о будущем CLV. Поэтому случайный сплит корректен.

## 4. Baseline-модель

- **Модель:** Lasso-регрессия на исходных признаках (без feature engineering).
- **Результаты:** 
  - RMSE = 350.13
  - MAE = 236.07
  - R2 = 0.853
- **Цель:** установить нижнюю планку качества для сравнения с более сложными моделями.

## 6. Финальная модель и интерпретируемость

- **Обоснование выбора финальной модели:** Модель CatBoost (default) показала наименьшую ошибку RMSE на валидации (225.10) и самое высокое R² (0.939). Она также стабильна на тесте:
- Тестовая оценка: RMSE = 224.85, MAE = 150.92, R² = 0.940.
CatBoost автоматически обрабатывает категориальные признаки, не требует тщательной настройки и даёт хорошую обобщающую способность.
- **Интерпретируемость:** CatBoost предоставляет важность признаков (feature importance). Наиболее значимые признаки:
- `Total_Purchases` (количество покупок)
- `Average_Order_Value` (средний чек)
- `Login_Session_Product` (созданный признак)
- `Recency_Score` (давность последней покупки)

Это логично: клиенты, которые часто покупают, тратят больше за раз и недавно совершали покупки, приносят наибольший CLV.
